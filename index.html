📦 O que é o planejador-de-rotas?

É um programa para Windows que organiza automaticamente a melhor ordem de entregas baseado no CEP de cada parada. Ele resolve o clássico problema do caixeiro-viajante (TSP) — ou seja, encontra o caminho mais curto para visitar todos os pontos — e desenha o trajeto num mapa interativo. Você só informa os CEPs, e o app gera uma rota otimizada, com indicações visuais e ordem de parada.

Perfeito para pequenos negócios, entregadores autônomos, motoristas de aplicativo e qualquer pessoa que faça múltiplas entregas por dia. Reduza combustível, tempo e estresse no trânsito.

2 Encontre a versão para Windows

Na página do GitHub, clique na aba “Releases” (ou “Versões”) no lado direito. Baixe o arquivo mais recente, geralmente nomeado como planejador-de-rotas-windows.zip ou similar. Não precisa instalar nada antes — é um aplicativo portátil.

4 Execute o aplicativo

Dentro da pasta extraída, localize o arquivo planejador-de-rotas.exe (ou app.exe) e dê dois cliques. Pronto! A interface abre no seu navegador padrão automaticamente (endereço http://localhost:3000).

🔒 Dica de segurança: o Windows pode mostrar o aviso "Mais informações" ou "Executar assim mesmo" — isso é normal porque o aplicativo não possui certificado pago. Clique em "Executar assim mesmo". É um software open-source e seguro.

📋 Como usar o planejador

  1. Adicione seus CEPs — digite ou cole uma lista de CEPs no campo de texto (pode separar por vírgula ou nova linha).
  2. Clique em "Otimizar rota" — o app consulta os endereços, calcula a sequência ideal e exibe o mapa com marcadores numerados.
  3. Visualize a ordem — cada marcador mostra o número da parada. A linha traça o percurso mais curto.
  4. Exportar ou imprimir — você pode salvar a rota como imagem ou copiar a lista ordenada.

Não precisa de conhecimento técnico. Se errar um CEP, o app avisa e você corrige.

🛠️ Quais tecnologias estão por trás?

Por baixo do capô, o aplicativo usa um conjunto moderno e confiável:

  • Next.js + React — interface rápida e agradável.
  • Leaflet + OpenStreetMap — mapas gratuitos e detalhados.
  • OSRM — motor de roteamento que calcula as distâncias reais.
  • Fastify + zod — backend eficiente e validação de dados.
  • Turborepo — organização profissional do código.

Tudo integrado para você ter a melhor experiência.
